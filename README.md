# 收支记账本

手机端优先的收支记账网页。单文件、纯前端、无需服务器和构建步骤。

**在线使用：** 部署到 GitHub Pages 后，用手机浏览器打开仓库的 Pages 地址即可。

## 功能

- **三类账目**：收入 / 必要支出 / 可选支出，其中「必要支出」是独立分类（默认选中），列表带「必要」徽标，统计中单独成栏
- **移动端优先**：底部四页导航（记账 / 明细 / 统计 / 设置）、大号金额输入框（自动唤起数字键盘）、触控区域 ≥ 44px、适配 iPhone 刘海与底部横条、支持「添加到主屏幕」当 App 用
- **数据持久化**：记录实时存入浏览器本地存储，重开页面 / 重启手机自动加载历史数据；localStorage 不可用时自动降级到 sessionStorage 或内存，并给出提示
- **云同步（可选）**：填入 GitHub 细粒度令牌后，数据汇总到仓库里的一个 JSON 文件，**多端看到同一份数据**——打开页面自动拉取、关闭页面自动上传，无需后台轮询；记录级合并避免多端互相覆盖，删除也会同步
- **备份与恢复**：导出 `.json` 备份（按记录去重导入，可换手机恢复）、导出 `.csv` 表格（带 BOM，Excel 不乱码）
- **统计分析**：收入 / 必要支出 / 可选支出 / 结余汇总，必要支出占支出比例，近 6 个月趋势图，按分类构成排行
- **筛选**：按类型 + 按月份组合筛选

## 云同步：多设备共享同一个 JSON 文件

页面本身没有后端，但可以直接调用 **GitHub Contents API** 把数据读写到你仓库里的一个 JSON 文件，从而实现多设备同步与云端备份。整个机制不需要任何服务器。

### 工作方式

```
手机浏览器 ─┐
           ├─→ GitHub Contents API ─→ 仓库里的 data/ledger.json
电脑浏览器 ─┘
```

**打开时拉取，关闭时上传** —— 这是唯一的同步时机，没有后台轮询：

1. **打开页面**：拉取云端最新数据，与本机已有的合并（所以换设备一打开就能看到全部记录）
2. **关闭页面 / 切到后台**：把本机改动写入云端文件
3. 断网时照常记账（先存本机），下次打开会自动合并上传

因为两端读写的是同一个文件，**多端看到的是同一份数据**。

### 两种写入方式（设置里可切换）

| 模式 | 关闭时的行为 | 说明 |
| --- | --- | --- |
| 🛡️ 安全模式（默认） | 先把云端数据拉下来合并，再整份写回 | 两端先后关闭也不会覆盖对方的记录 |
| 直接覆写 | 不拉取，直接把本机数据整份覆盖云端 | 更快，但"后关闭的一方"会盖掉"先关闭方"在关闭前的改动 |

两种模式下，如果云端文件在你这次操作期间被别人改过，GitHub 会返回 409，程序会**自动先合并再写**，因此不会静默丢数据。真正的差异只出现在"一端离线期间记了账、期间另一端改过云端"这类场景，此时覆写模式会以最后关闭的那台为准。

### 关于"每次修改只改这个文件"

数据确实只写这一个 JSON 文件，但**不是无脑整文件覆盖**：文件里每条记录都带 `updatedAt` 时间戳，合并时按记录 id 取并集、同一 id 取更新的那方。原因很实际——如果每次都无脑覆盖，手机和电脑同时记账必然互相丢失。删除操作则通过"删除标记"传播，避免删掉的记录被另一端合并回来。

### 配置步骤

1. **创建令牌**：打开 <https://github.com/settings/personal-access-tokens/new>
   - Token name 随便填，例如 `ledger-sync`
   - Expiration 建议选较长时间（如 1 年），到期后重新生成
   - **Repository access** 选 `Only select repositories`，只勾选 `ledger` 这一个仓库
   - **Permissions** → `Repository permissions` → 找到 **Contents**，设为 **Read and write**
   - 点 Generate token，复制生成的 `github_pat_...`（只显示一次）

2. **在网页里填写**：打开网页 → 底部「设置」→「云同步」
   - 仓库：`你的用户名/ledger`
   - 访问令牌：粘贴刚才的令牌
   - 数据文件路径：保持默认 `data/ledger.json` 即可
   - 点「连接并同步」

3. **其他设备**重复第 2 步（填同一个仓库和令牌），即可看到全部数据

### 隐私提示

- **公开仓库**：任何人只要知道仓库地址，就能看到 `data/ledger.json` 里的账目。介意的话把仓库设为 **Private**——同步功能完全不受影响（细粒度令牌可以授权私有仓库）。
- 令牌只保存在你本机浏览器的本地存储里，不会写入仓库、不会发给任何第三方；所有请求都直接发往 `api.github.com`。
- 换设备或不再使用时，随时可以到 GitHub 设置里吊销该令牌。
- 「断开连接」会清除本机保存的令牌，但不会删除云端文件。

### 冲突处理

每次上传都会带上云端文件的版本号（sha），如果期间别的设备改过文件，GitHub 会返回 409。程序收到 409 会自动**先拉取合并、再重试上传**，因此两端的数据都会保留，不需要你手动处理。

### 不用云同步行不行

完全可以。不填令牌时程序不会发起任何网络请求，和纯本地版本行为一致（已有测试覆盖这一点）。手动备份可以用「设置 → 导出备份文件」。

## 部署到 GitHub Pages

### 方式一：网页上传（不需要安装任何工具）

1. 打开 <https://github.com/new> 新建仓库，例如命名 `ledger`，选择 **Public**，点 **Create repository**
2. 在仓库页面点 **uploading an existing file**
3. 把本目录下的 `index.html` 拖进去，点 **Commit changes**
4. 进入仓库 **Settings → Pages**，`Source` 选 **Deploy from a branch**，`Branch` 选 **main** + **/ (root)**，点 **Save**
5. 等 1–2 分钟，访问 `https://你的用户名.github.io/ledger/`

### 方式二：命令行

```bash
git init
git add index.html README.md
git commit -m "收支记账本：手机端优先的收支记录网页"
git branch -M main
git remote add origin https://github.com/你的用户名/ledger.git
git push -u origin main
```

然后在 **Settings → Pages** 里把 Source 设为 `main` / `/ (root)`。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 主程序，GitHub Pages 默认打开这个文件 |
| `收支记账本.html` | 同一份程序的中文文件名副本，方便直接下载后双击本地使用 |

## 数据存储说明

- 数据保存在**访问者的浏览器**里（按域名区分），不会上传到任何服务器，仓库里也不含任何个人数据
- 因为是纯静态页面，**不同设备之间的数据不互通**；换设备时用「设置 → 导出备份文件」再在新设备「从备份恢复」
- 注意：如果之后同时用 `https://用户名.github.io/ledger/` 和本地双击打开的 `file://` 版本，两者数据是分开的

## 技术说明

- 单个 HTML 文件，内含全部 CSS 与原生 JavaScript，无外部依赖、无 CDN 请求
- 可直接双击本地打开使用，也可放到任意静态托管上（GitHub Pages / Cloudflare Pages / Vercel 均可）
